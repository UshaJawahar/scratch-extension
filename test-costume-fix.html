ML Extension Costume Image Fix Test

Test Instructions

This test verifies that the ML extension can properly capture costume images using the new data URI approach.

  1. Open Scratch GUI in another tab
  2. Add a sprite with a costume
  3. Load the ML extension
  4. Run the test functions below

Test Functions

Open the browser console and run these functions:

// Test costume image capture
window.testCostumeImage()

// Test full prediction flow
window.testPrediction()

// Check if ML extension is loaded
console.log('ML Extension loaded:', !!window.MLExtension)

Expected Results

  • testCostumeImage() should return a data URI starting with "data:image/"
  • testPrediction() should attempt to make a prediction (may fail if no project is loaded)
  • No more "Costume: undefined" errors in console

Console Output Analysis

Look for these log messages in the console:

  • ML Extension: costumeImage called
  • ML Extension: Current costume: [object]
  • ML Extension: Costume properties: {...}
  • ML Extension: Data URI length: [number]
  • ML Extension: Data URI preview: data:image/...

Previous Error (Should be Fixed)

These errors should no longer appear:

  • ML Extension: Costume: undefined
  • ML Extension: Costume bitmapResolution: undefined
  • ML Extension: No costume or bitmapResolution
